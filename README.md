
# E-Commerce Website – Task 4

A full-stack e-commerce application developed for the Auspify programme.

## Technologies
- HTML, CSS and JavaScript
- Node.js and Express.js
- SQLite (better-sqlite3)
- bcryptjs
- express-session

## Features
- Product catalogue
- Product management APIs
- Shopping cart and checkout
- Customer registration and login
- Order management
- Administrator dashboard
- Administrator access control

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

   npm install

4. Start the server:

   node server.js

5. Open the website:

   http://localhost:3000

## Administrator Dashboard

The administrator dashboard is available to authenticated administrator accounts.

## Database

The application uses SQLite to store products, users and customer orders.
